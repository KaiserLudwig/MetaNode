📝 Blog API

个人博客系统后端 · Go + Gin + GORM + JWT · 服务运行中

🎯 演示账号：demo / demo123456  ·  认证方式：Authorization: Bearer <token>
方法路径认证说明
GET/api/v1/healthz-健康检查
POST/api/v1/auth/register-注册 {username, password, email}
POST/api/v1/auth/login-登录，返回 JWT + 用户信息
GET/api/v1/auth/me✅当前登录用户信息
GET/api/v1/posts?page=1&size=10-文章列表（分页，含作者与评论数）
GET/api/v1/posts/:id-文章详情
POST/api/v1/posts✅创建文章 {title, content}
PUT/api/v1/posts/:id✅ 作者更新文章（部分字段更新）
DELETE/api/v1/posts/:id✅ 作者删除文章（级联删除评论）
GET/api/v1/posts/:id/comments-文章评论列表
POST/api/v1/posts/:id/comments✅发表评论 {content}

快速体验：

# 登录拿令牌
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123456"}'

# 查看文章列表
curl http://localhost:8080/api/v1/posts
Blog Backend · 统一响应 {code, message, data} · 未知路径返回 JSON 404
